# Web Security Research

个人 Web 安全漏洞复现与分析项目，基于 PortSwigger Web Security Academy 靶场进行实战学习，针对 OWASP Top 10 常见漏洞进行复现、分析并输出报告。

## 研究方向

- Web 漏洞复现与原理分析
- 渗透测试方法论
- 漏洞修复建议

## 报告列表

| 漏洞名称 | 入口 | 类型 |
|---------|------|------|
| CSRF Token验证取决于请求方法 | 从业者 | CSRF |
| XSS漏洞-AngularJS表达式注入 | 从业者 | XSS |
| SQL注入漏洞-布尔盲注分析 | 从业者 | SQL注入 |
| SQL注入漏洞-联合注入分析 | 学徒/从业者 | SQL注入 |
| 文件上传漏洞-路径绕过 | 从业者 | 文件上传 |

## 工具

- Burp Suite
- PortSwigger Web Security Academy
- Python自动化脚本（盲注等场景）

本项目所有内容均在合法授权的靶场环境中完成，仅用于安全学习目的。
